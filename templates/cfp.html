Call for Proposals

Software Should Work is looking for engineers to present 7-minute lightning talks. The topics below are good starting points, but we're open to a broad range of possibilities.

  • Reliability
  • Performance
  • Testing
  • Databases
  • Programming languages
  • Infrastructure
  • Web development

Because each slot is short, talks should get to the point quickly. Technical depth is welcome.

Accepted talks do not include free admission so selected speakers should plan to purchase a ticket.
